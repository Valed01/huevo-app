Неофициальный open-source клиент соцсети [huevo.su](https://huevo.su) на React Native + Expo.
Пока только Android.

Автор — [Rubi](https://huevo.su/rubi). По всем вопросам и предложениям пишите мне на huEVO.

> Это сторонний проект, не связанный с администрацией huEVO.

## Как устроено

Простая WebView-обёртка: приложение открывает https://huevo.su на весь экран с родным интерфейсом сайта
(включая его мобильный таб-бар). Сверху только то, чего не умеет вкладка браузера:

- обновление страницы жестом «потянуть вниз» (нативный спиннер Android); не мешает прокрутке чатов, списков и меню;
- системная кнопка «назад» листает историю сайта, на стартовой странице выходит из приложения;
- ссылки на другие сайты открываются во внешнем браузере;
- полосы под строкой состояния и жестами продолжают цвет шапки и нижней панели сайта (с учётом темы);
- экран ошибки с «Повторить», если нет сети; перезапуск WebView, если его процесс упал;
- разрешения на уведомления, микрофон и камеру приложение запрашивает один раз при первом запуске;
- ссылки на huevo.su можно открывать в приложении (Открывать по умолчанию → Добавить ссылки);
- музыка с сайта в шторке и на экране блокировки: обложка, пауза, следующий/предыдущий трек, перемотка.
  Плеер сайта публикует трек через `navigator.mediaSession`, которого в Android WebView нет: приложение
  подставляет свою реализацию и показывает нативное медиа-уведомление (`modules/huevo-media`, Kotlin + MediaSession);
- уведомления о новых сообщениях и событиях: раз в ~5 минут (цепочка задач WorkManager плюс 15-минутная страховка, только при наличии сети) приложение
  спрашивает у сайта `/api/unread_counts` — тот же запрос, что делает сам сайт. Без постоянного сервиса и открытых
  соединений, поэтому батарею не расходует. Пока приложение открыто, уведомлений нет (сайт показывает свои);
  нажатие открывает нужный чат или страницу. Если приложение не открывать больше 3 дней, у сайта истекает
  проверка браузера и уведомления приостанавливаются до следующего запуска;
- обновления: раз в день приложение проверяет GitHub Releases этого репозитория. Если вышла новая версия, приходит
  уведомление, а в приложении показывается окно со списком изменений из текста релиза и кнопками «Установить»
  (скачивает APK и открывает системный установщик), «Позже» (через сутки) и «Не показывать для этой версии»;
- редактор тем: встроенное расширение [huEVO Themes](extensions/huevo-themes/NOTICE.md) by neriusshadow (с разрешения автора).
  Пункт «Темы оформления» в боковом меню, меню аватарки и «Настройки → Оформление»; по умолчанию тема «Стандартная» (сайт без изменений);
- к User-Agent добавлено `huEVOApp/<версия>`, чтобы админы видели трафик приложения.

```
src/
  app/_layout.tsx          корневой layout
  app/index.tsx            экран: системные панели + WebView
  components/site-webview.tsx
  lib/site.ts              адрес сайта, User-Agent, инжекты (цвета панелей, mediaSession, UI приложения)
modules/huevo-media/       нативный модуль: MediaSession + foreground-сервис с уведомлением плеера
modules/huevo-notify/      нативный модуль: фоновая проверка (WorkManager) и системные уведомления
modules/huevo-update/      нативный модуль: ежедневная проверка релизов, скачивание и установка APK
modules/huevo-themes/      нативный модуль: отдаёт файлы тем по https://huevo.su/__huevo_themes__/, сохраняет экспорт
extensions/huevo-themes/   расширение huEVO Themes без изменений
src/themes/                адаптация расширения: chrome.* API, кнопки в меню, мобильный вид редактора
scripts/build-themes.mjs   собирает расширение в ассеты модуля (запускается при npm install)
patches/                   patch-package: хук перехвата запросов в react-native-webview
```

## Запуск

Нужны Node 20+, JDK 17, Android SDK (или эмулятор/телефон с отладкой по USB).
Expo Go не подойдёт, потому что `react-native-webview` требует development build.

```bash
npm install
npm run android        # expo run:android: собрать и поставить dev build
```

Без локального Android SDK можно собрать в облаке: `npx eas-cli@latest build -p android --profile development`.

Проверки: `npm run typecheck && npm run lint`.

После правок в `extensions/` или `src/themes/` пересоберите ассеты: `npm run themes`.
Отладка страницы в `chrome://inspect`: соберите с `EXPO_PUBLIC_WEBVIEW_DEBUG=1`.

## Сборка в GitHub Actions

Каждый push в `main` собирает универсальный APK (arm64-v8a, x86_64), его можно скачать в артефактах запуска.
Тег `v*` (например, `git tag v0.2.0 && git push --tags`) дополнительно публикует APK в Releases: версия приложения
берётся из тега, а текст релиза собирается из заголовков коммитов с прошлого релиза (его можно отредактировать
на GitHub, именно он показывается в окне обновления).

Для подписи релизным ключом добавьте секреты репозитория: `ANDROID_KEYSTORE_BASE64`,
`ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Без них APK подписан debug-ключом.

## Проверка подлинности

Релизы собирает GitHub Actions прямо из этого репозитория, без ручных шагов. Проверить скачанный APK можно тремя способами.

**1. Собран из этого репозитория** — подписанная аттестация сборки (Sigstore). Подтверждает, что файл собран
workflow `android.yml` этого репозитория из конкретного коммита:

```bash
gh attestation verify huevo-v1.0.0.apk -R Valed01/huevo-app
```

Аттестации всех сборок: https://github.com/Valed01/huevo-app/attestations

**2. Файл не повреждён и не подменён** — контрольная сумма из релиза:

```bash
sha256sum -c huevo-v1.0.0.apk.sha256
```

**3. Подписан ключом проекта** — отпечаток сертификата (`apksigner verify --print-certs huevo-v1.0.0.apk`,
строка `certificate SHA-256 digest`) должен совпадать:

```
EA:3A:44:72:89:23:6D:22:AD:3C:51:7F:CD:4D:C3:AA:96:F2:24:61:49:3E:46:C5:E7:2D:10:B0:06:61:5B:EE
```

Android сам не даст поставить обновление, подписанное другим ключом.

## Известные ограничения

- **Вход через Google:** Google не пускает свой вход во встроенные браузеры, поэтому страница Google открывается
  во вкладке Chrome (Custom Tab), а возврат на huevo.su приходит обратно в приложение. Для этого ссылки huevo.su
  должны открываться в huEVO: Настройки → Приложения → huEVO → Открывать по умолчанию → Добавить ссылки.
- **Push-уведомлений нет** (у сайта нет push-сервера): приложение само проверяет новое раз в ~5 минут, мгновенными они не будут.
- **OnePlus/ColorOS:** для фоновых проверок нужно разрешить huEVO «Фоновую активность» и «Автозапуск», иначе система не будит закрытое приложение.
