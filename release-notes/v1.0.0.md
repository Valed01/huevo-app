Первый публичный релиз неофициального клиента huEVO для Android.

### Что есть
- Сайт huEVO в приложении на весь экран, с родным интерфейсом и нижней панелью
- Уведомления о новых сообщениях и событиях (проверка раз в ~5 минут, без расхода батареи)
- Музыка в шторке и на экране блокировки: обложка, пауза, переключение треков, перемотка
- Голосовые сообщения и звонки (доступ к микрофону и камере)
- Редактор тем оформления (huEVO Themes by neriusshadow): готовые темы, обои, цвета, эффекты, импорт и экспорт `.hvthm`
- Ссылки huevo.su открываются в приложении, вход через Google
- Обновление страницы жестом «потянуть вниз»
- Проверка обновлений: приложение само сообщит о новой версии

### Установка
Скачайте `huevo-v1.0.0.apk` ниже и установите (Android попросит разрешить установку из этого источника).
Если у вас стояла тестовая сборка, сначала удалите её: она подписана другим ключом.

На OnePlus и других ColorOS для уведомлений разрешите приложению «Фоновую активность» и «Автозапуск».

### Проверка подлинности
APK собран GitHub Actions из исходного кода этого репозитория, у сборки есть подписанная аттестация. Как проверить — в разделе «Проверка подлинности» в README.
